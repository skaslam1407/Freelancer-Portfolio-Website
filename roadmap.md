# Product Roadmap

## MVP

- Premium portfolio website
- Supabase backend
- Admin authentication
- Project CRUD
- Media management
- Services/skills/experience/testimonials
- Draft/publish
- Contact form
- SEO
- Responsive design
- Vercel deployment

## V1

- Rich project case studies
- Blog
- Search/filter
- Analytics
- Contact notifications
- Better media processing
- Admin activity log

## V2

- Multiple admin roles
- MFA
- Content versioning
- Scheduled publishing
- Advanced analytics
- Newsletter
- Testimonials workflow
- AI-assisted content drafting

## Non-Goals for MVP

- Multi-tenant CMS
- Full enterprise CMS
- Complex role hierarchy
- Heavy custom backend
- Large video hosting platform
- Over-engineered microservices
