# Design System

## Design Direction

Premium, modern, minimal, editorial, developer-focused.

Avoid generic template aesthetics. Use strong typography, spacing, visual hierarchy, restrained motion, and high-quality project imagery.

## Visual Principles

- Strong hero statement.
- Clear typography hierarchy.
- Generous whitespace.
- Consistent grid.
- High contrast.
- Subtle borders and surfaces.
- Purposeful motion.
- Strong project storytelling.
- Mobile-first layout.

## Responsive Breakpoints

Use the framework's standard responsive system rather than hard-coding excessive breakpoints.

Target:
- Mobile
- Tablet
- Desktop
- Large desktop

## Components

## Accessibility

- Keyboard navigation.
- Visible focus states.
- Semantic HTML.
- Correct heading hierarchy.
- Form labels and errors.
- Alt text.
- Reduced-motion support.
- Adequate color contrast.
- No information conveyed by color alone.
