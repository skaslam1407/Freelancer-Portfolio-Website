# SEO and Performance

## SEO

Every public page should have:
- Unique title
- Meta description
- Canonical URL where needed
- Open Graph metadata
- Twitter/X metadata
- Semantic headings

Projects should generate metadata from database content.

## Technical SEO

- `robots.txt`
- `sitemap.xml`
- Canonical URLs
- Clean slugs
- 404 page
- Structured data where appropriate

## Performance

Priorities:
1. Fast LCP.
2. Stable layout / low CLS.
3. Responsive interaction / low INP.
4. Minimal client-side JavaScript.
5. Optimized images.
6. Lazy-load non-critical media.
7. Avoid autoplay-heavy video above the fold.
8. Cache public content where appropriate.

## Media

Use responsive image sizing.

Avoid serving original multi-megabyte images to mobile devices.

For video, prefer poster images and lazy loading; use external video infrastructure when portfolio videos become large.
